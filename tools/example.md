# Simple Reading · 本地自测清单（放 Dnotes 里照着走）

## 一、准备

1. 库里有一个 **PDF** 和一个 **EPUB**（哪本都行）。
2. 在书旁边建一个**同名 md**（插件不代建）：
   - `我的书.pdf` → 旁边建 `我的书.md`
   - `我的书.epub` → 旁边建 `我的书.md`

## 二、PDF 路径

1. 双击 PDF，用 Obsidian 自带阅读器打开。
2. 鼠标选中一段文字。
3. 命令面板 → **摘录到读书笔记**。
4. 打开同名 md，应当看到：

```markdown
来源：[[我的书.pdf]]

> [!quote] 摘录 · 我的书.pdf · 第 N 页 · YYYY-MM-DD HH:mm
> 选中的原文
>
> — [[我的书.pdf]] · 第 N 页
```

5. 再选中一段 → **记录想法到读书笔记** → 弹框里写一句话 → 保存：

```markdown
> [!note] 想法 · 我的书.pdf · 第 N 页 · YYYY-MM-DD HH:mm
> 你写的想法
>
> 选中的原文
>
> — [[我的书.pdf]] · 第 N 页
```

## 三、EPUB 路径

1. 文件浏览器里点 `.epub` → 应当用**内置阅读器**打开（不是"无法打开"）。
2. 顶栏：左侧书名、中间章节下拉、右侧「‹ 上一章 / 下一章 ›」；底部右下是 `x / y` 进度。
3. 背景 / 文字颜色应跟随当前 Obsidian 主题（切一下主题看效果）。
4. 选中正文文字 → **摘录到读书笔记** → 同上，只是位置显示"第 N 章"。
5. 关掉再打开这个 epub，应当回到上次那一章。

## 四、写入位置

设置 → Simple Reading：

- **写入位置** = 文末 → 每次都追加到笔记最后。
- **写入位置** = 指定标题之下，**目标标题** = `摘录` → 笔记里要有 `## 摘录`（或任意级别的同名标题）；
  新的条目会插在**那个小节的末尾**（顺序追加），标题不存在时会退回文末并在提示里告诉你。

## 五、可卸载性验证（关键）

1. 随便翻几篇笔记，确认除了你自己勾选的"摘录 / 想法"块之外，没有别的东西被写进去。
2. 禁用插件 → 打开 PDF / EPUB → **文件本身随时可以正常打开**（插件从没写过它们）。
3. 笔记里的 callout 是普通 Markdown，禁用插件后照常显示。

## 六、已知边界（不算 bug）

- 在 PDF 里**不会画常驻高亮**：要求 6 说原文件不能改，写进 PDF 就破坏文件、写进插件私有数据又违背"数据不被软件绑定"。所以高亮落在笔记里，带一条指回页码的链接。
- 页码识别依赖自带阅读器的 DOM（`data-page-number`）。若某次识别不到，位置部分会留空，不影响摘录。
- EPUB 忽略书自带的 CSS（按需求 10：跟随 Obsidian 主题）。
